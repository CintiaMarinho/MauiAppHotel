# 🏨 App Hotel

## 📌 Sobre o projeto

O App Hotel é um aplicativo desenvolvido como atividade prática da disciplina de Desenvolvimento de Sistemas II, utilizando .NET MAUI e C#.

O aplicativo permite visualizar uma tela de contratação de hospedagem, informar a quantidade de adultos e crianças, selecionar uma acomodação e informar as datas de check-in e check-out.

## 🎯 Objetivo

Desenvolver e personalizar uma interface de aplicativo mobile, aplicando os conhecimentos adquiridos durante as aulas.

## 🛠️ Tecnologias utilizadas

- C#
- .NET MAUI
- XAML
- Visual Studio 2026

## 📱 Funcionalidades

- Tela principal personalizada
- Seleção de quantidade de adultos e crianças
- Seleção de acomodação
- Informações de check-in e check-out
- Tela Sobre com informações do projeto e da desenvolvedora
